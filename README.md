# Parker Desktop

A fox companion for questions, research and tasks using your own connected account.

[Download the latest signed Mac release](https://github.com/Parkerconsulting/parker-desktop-releases/releases/latest)

Mac installers are signed with Andrewe Parker’s Apple Developer ID and notarized by Apple. Choose arm64 for Apple silicon or x64 for Intel. The release includes a setup guide and walkthrough video.

Updates download automatically while Parker runs. You choose when to restart and install. Initial setup requires your own ChatGPT account. Your local account credentials, conversations and company knowledge are not included in these downloads.

Windows signing is still pending. Intel builds are notarized, but physical Intel hardware testing is outstanding.

This repository contains distribution information and release assets. Application source is private.
